# \# 🇻🇳 1975 Historical Campaign Website

# 

# This project is an educational historical website developed for the VNR course.  

# The website provides information about the 1975 Spring Offensive Campaign and important historical events that led to the reunification of Vietnam.

# 

# The platform is designed to present historical content in a modern, responsive, and user-friendly way through interactive layouts and structured information.

# 

# > ⚠️ This project was developed for educational and academic purposes only.

# 

# \---

# 

# \# ✨ Features

# 

# \- 📖 Overview of the 1975 Campaign

# \- 🕰️ Historical timeline of important events

# \- 🪖 Information about major military operations

# \- 👤 Historical figures and leadership information

# \- 🗺️ Campaign maps and historical references

# \- 🖼️ Image gallery and historical media

# \- 📱 Responsive design for desktop and mobile devices

# \- 🔍 Easy navigation and organized content structure

#
